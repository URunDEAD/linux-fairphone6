# Licensing and redistribution boundaries

The original MIT license and copyright notice are retained at the repository root for original project-owned material. It does not relicense third-party patches, drivers, configs or tuning data. Preserve file-level SPDX headers, patch authors, original notices and upstream provenance.

- Linux patch material and driver derivatives retain the applicable Linux/source-file licensing. The S5KKD1 driver declares GPL-2.0-only.
- libcamera patches retain upstream/downstream authorship and terms; `userspace/camera/libcamera/patches/README.txt` and `APKBUILD` record the source base. Tuning comments retain their original attribution.
- Fingerprint and IMS package metadata identify their upstream software and licenses; fetched dependencies retain those licenses.
- ALSA UCM profiles, compatibility patches and other imported material keep their original project/file terms. The top-level MIT notice is not a blanket assertion for every file.
- Vendor firmware, trustlets, calibration data and binary boot inputs are excluded. Public availability of vendor material is not permission to redistribute it. Hashes and extraction tools are not a license grant.

This repository is private pending a later publication decision. The source was already public, but any future public release still needs review of uncertain third-party attribution/terms. No DCO sign-off or upstream submission is added on anyone's behalf.
